# Sewing Production System

Веб-система производственного учёта для швейного цеха. Приложение помогает фиксировать работу кройщиков и швей, контролировать партии и остатки, учитывать брак и рассчитывать заработок сотрудников.

> Репозиторий содержит обезличенную копию исходного кода для демонстрации проекта. Производственная база данных, реальные учётные записи, пароли и данные сотрудников не публикуются.

## Возможности

- авторизация и разграничение доступа по ролям;
- управление сотрудниками, моделями, операциями и расценками;
- создание и закрытие производственных партий;
- учёт работы кройщиков и швей по размерам и операциям;
- контроль доступных остатков и защита от сверхсписания;
- учёт годной продукции и брака;
- расчёт заработка за выбранный период;
- история операций с фильтрацией и отменой ошибочных записей;
- журналирование административных действий;
- экспорт отчётов в Excel;
- адаптивный интерфейс для работы со смартфона.

## Технологии

- Node.js и Express;
- PostgreSQL;
- HTML, CSS и JavaScript;
- JWT-аутентификация в защищённой cookie;
- Docker Compose;
- Caddy как reverse proxy;
- ExcelJS для формирования отчётов.

## Архитектура

```text
Браузер / смартфон
        │
      Caddy
        │
Express API ─── PostgreSQL
        │
Статический веб-интерфейс
```

Основная бизнес-логика и REST API находятся в `src/server.js`, схема базы данных — в `src/schema.js`, клиентское приложение — в каталоге `public`.

## Локальный запуск

Требуются Docker и Docker Compose.

1. Создайте локальный файл настроек:

   ```bash
   cp .env.example .env
   ```

2. Замените значения `POSTGRES_PASSWORD` и `JWT_SECRET` на собственные случайные секреты.

3. Для локального знакомства с интерфейсом можно временно установить:

   ```dotenv
   SEED_DEMO_DATA=true
   ```

   Эта настройка создаёт только вымышленные аккаунты и демонстрационные данные. Не используйте её в рабочем окружении.

4. Запустите приложение:

   ```bash
   docker compose up --build
   ```

5. Откройте адрес, заданный в `APP_DOMAIN`.

## Безопасность

- файл `.env` исключён из Git;
- рабочие базы, резервные копии, выгрузки и ключи исключены;
- тестовые данные отключены по умолчанию;
- реальные сведения о сотрудниках и заказчике в репозиторий не включены;
- перед рабочим развёртыванием необходимо заменить все секреты и создать собственные учётные записи.
